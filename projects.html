LeakFence Local

A Manifest V3 browser extension that stops API keys, tokens, private keys and recovery phrases from being pasted into AI chat sites. Fully on-device: no server, and secrets are kept only as local HMAC-SHA-256 fingerprints. Open source, English and Polish UI. Available on the Chrome Web Store.
